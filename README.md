# 🌐 English Landing Page - Front-End Demo

*Read in Portuguese below* | *Leia em Português abaixo*

This is a demonstration project focused on building a responsive landing page. A key highlight of this repository is that the entire codebase (HTML structure, CSS classes, JavaScript logic, and semantics) was written **100% in English**, strictly following the best practices of the global tech industry.

⚠️ **Project Status:** This application serves as a Front-End showcase. It utilizes JavaScript for interface interactions and dynamic behaviors, but it does not contain back-end functionalities or a database. The main goal is to demonstrate Front-End skills, structure, and responsiveness.

* HTML5
